# Image assets for the README

Drop the following files in this folder. The README already references them, so
the images appear automatically once the files exist.

| File | Purpose | Recommended size |
| --- | --- | --- |
| `logo.png` | Project logo shown at the top of the README | 512x512, transparent PNG |
| `dashboard.png` | Hero screenshot: Dashboard with the engine running | 1600x1000 |
| `configuration.png` | Configuration page in edit mode | 1600x1000 |
| `console.png` | Live console with Debug Mode enabled | 1600x600 |
| `faq.png` | FAQ and Help page | 1600x1000 |
| `contact.png` | Contact page | 1600x1000 |
| `banner.png` | Optional wide footer banner | 1600x400 |

## Tips

- Capture screenshots at 100% display scaling with the window maximized for crisp edges.
- Keep the dark theme visible; do not add light borders or drop shadows.
- PNG is preferred over JPEG so the purple gradients stay clean.
- `assets/icon.png` can be reused as `logo.png` if you do not have a dedicated logo.
